# Доставка через ПВЗ OZON и Wildberries — исследование

**Статус:** исследование, не ТЗ. Решение по подключению после СДЭК — за владельцем.
**Проверено:** 2026-06-21.

Связанные документы: [delivery-options.md](delivery-options.md) (карта развития
способов доставки и зафиксированный порядок), [cdek-pvz.md](done/cdek-pvz.md)
(реализованная нейтральная модель ПВЗ), [admin-orders.md](done/admin-orders.md)
(snapshot доставки в заказе).

## Короткий вывод

| Перевозчик | Можно ли возить заказы своего сайта в их ПВЗ | Чем именно |
|---|---|---|
| **OZON** | **Да.** Есть готовый продукт «Ozon Доставка» (Ozon Логистика) для сторонних интернет-магазинов с публичным API. | Сеть 85 000+ ПВЗ/постаматов, последняя миля и возвраты силами Ozon. |
| **Wildberries** | **Нет** аналога на 2026-06. Возить заказы своего магазина в ПВЗ WB как через перевозчика — нельзя. | Есть только: WB API для продавцов *на* маркетплейсе (FBS/FBO) и WB Track — пересылка личных посылок между ПВЗ (C2C). Ни то, ни другое не подходит для checkout стороннего магазина. |

Практический итог для МАВИТА: **реальный кандидат — только Ozon Доставка.** WB на
сегодня закрыт; вернуться к нему стоит, только если появится прямой 3PL-сервис
«доставка заказов внешних магазинов в ПВЗ WB».

## OZON — «Ozon Доставка» (Ozon Логистика)

### Что это

Сервис, который позволяет продавать товары на **своём** сайте/в приложении, а
доставку отдать Ozon. Покупатель оформляет заказ у вас, выбирает удобный ПВЗ или
постамат Ozon (или курьера), и получает заказ так же, как при покупке на самом
маркетплейсе. Это не витрина Ozon — товар не размещается в каталоге маркетплейса,
Ozon выступает чисто логистом.

- Покрытие: **85 000+ ПВЗ и постаматов** по почти всей РФ.
- Что делает Ozon: приёмка, упаковочная инфраструктура, маршрутизация,
  последняя миля, выдача в ПВЗ, обработка возвратов.
- **Комиссии за продажу нет** — платится только логистика (см. тариф ниже).

### Стоимость (главное за чем следить)

С **4 июня 2026** для выдачи заказов сторонних магазинов в ПВЗ Ozon Доставки
введён **фиксированный тариф 30 ₽ за товар** вместо прежнего процента.

- Раньше: 5–10 % от цены товара, но не более 250 ₽ за товар.
- Пример: два товара по 1000 и 3000 ₽ — было ~350 ₽ комиссии, стало 60 ₽.
- Последняя миля у Ozon оплачивается как «доставка до места выдачи» (не более
  ~25 ₽ за заказ); сама «выдача» с 2025 не тарифицируется отдельно.

⚠️ Источник (Oborot.ru) допускает, что 30 ₽ — **акционный тариф для набора базы**
и может вырасти. Перед запуском нужно подтвердить актуальную цену в ЛК Ozon и
заложить её как fixed-стоимость с запасом — ровно как сделано для СДЭК.

### Требования к подключению

- Продавец **из РФ**; работа по схемам **FBO и/или FBS** (то есть нужен
  оформленный кабинет продавца Ozon).
- Самозанятые на Ozon допускаются, **но** с ограничением: самозанятый не может
  перепродавать чужие товары и торговать чужими брендами — только собственного
  производства. Для свечей МАВИТА собственного производства это, скорее всего,
  проходит, но статус продавца и право торговли конкретной категорией нужно
  подтвердить в кабинете Ozon до интеграции.
- Подача заявки в личном кабинете → создание **private application** → настройка
  доступа разработчика → интеграция API.

### API (для нейтральной модели ПВЗ)

Авторизация Seller API: заголовки `Client-Id` + `Api-Key`.

| Назначение | Метод |
|---|---|
| Полный список ПВЗ (хранить у себя, обновлять во 2-й половине дня) | `POST v1/delivery/point/list` |
| ПВЗ для отрисовки на карте | `POST v1/delivery/map` |
| Информация о конкретном ПВЗ | `v1/delivery/point/info` |
| Создание отправления, печать этикетки, статусы/трекинг, отмены, возвраты | методы Seller API для Ozon Логистики (`dev.ozon.ru`, справочник методов) |

Для MVP (как с СДЭК) достаточно `point/list` + `point/info`: показать список ПВЗ
на checkout и подтвердить выбранный код на сервере. Создание отправления через
API — отдельный этап; на старте накладную можно оформлять в ЛК вручную.

### Как ложится на нашу архитектуру

Ozon Доставка укладывается в уже реализованную нейтральную модель из
[cdek-pvz.md](done/cdek-pvz.md) **без новых колонок**:

```text
delivery_carrier = 'ozon'
delivery_method  = 'ozon_pickup'
pickup_point_code / pickup_point_city / pickup_point_name / pickup_point_address
delivery_kopecks (fixed/0)  +  tracking_number
```

Нужен новый серверный прокси `/api/ozon` (по образцу `/api/cdek`): `Api-Key`
остаётся только на сервере, браузер получает список ПВЗ и отправляет код,
сервер повторно подтверждает код перед созданием заказа. Денежная схема — та же,
что у СДЭК: покупатель платит магазину одну сумму (товар + доставка) через
Робокассу; магазин отдельно рассчитывается с Ozon. Инвариант I10
(`items + delivery = total`) сохраняется.

## Wildberries — почему не подходит

На 2026-06 у WB **нет** продукта «доставь заказ своего магазина в наш ПВЗ».
Под «WB и доставка» обычно скрываются три разные вещи, ни одна из которых не
является интеграцией checkout для внешнего магазина:

1. **WB API для продавцов** (`dev.wildberries.ru`) — управление товарами,
   заказами, остатками и ценами **для тех, кто торгует на самом маркетплейсе**
   (FBS/FBO). Это не перевозчик для чужого сайта: товар обязан быть в каталоге WB.
2. **WB Track** — пересылка **личных посылок между ПВЗ** (C2C-сервис, как
   «отправить посылку другу»). Оформляется покупателем в приложении или на ПВЗ,
   оператор измеряет габариты и называет цену. Запущен пилотом в марте 2025,
   масштабирован на все ПВЗ РФ. Для автоматического оформления доставки в
   checkout интернет-магазина не предназначен.
3. Разговоры о выходе WB в смежные сегменты доставки — это **планы/потенциал**,
   а не готовый публичный 3PL-сервис с API на сегодня.

Вывод: обещать покупателю «доставку в ПВЗ Wildberries» нельзя — технической
возможности принять и развезти чужой заказ по сети WB как перевозчик сейчас нет.
Мониторить стоит появление именно «WB Доставки для бизнеса/интернет-магазинов»
с открытым API, аналогичной Ozon Доставке.

## Что это меняет в roadmap доставки

Это **не отменяет** зафиксированный порядок в [delivery-options.md](delivery-options.md)
(Релиз 1 — СДЭК до ПВЗ; калибровка; затем расширение). Уточнение лишь в том, что
строку «Ozon — не в roadmap» можно переоценить: **Ozon Доставка — рабочий
кандидат на роль второго ПВЗ-перевозчика** наравне с Яндекс Доставкой, потому что:

- ложится в существующую нейтральную модель (`ozon_pickup`) без миграций;
- даёт очень крупную сеть ПВЗ и предсказуемый плоский тариф (30 ₽/товар на 2026-06);
- API публичный, авторизация простая (`Client-Id`/`Api-Key`).

Сравнение второго перевозчика (после калибровки СДЭК):

| Критерий | Ozon Доставка | Яндекс Доставка |
|---|---|---|
| Сеть ПВЗ | 85 000+ ПВЗ/постаматов | крупная, + курьер/экспресс |
| Тариф | плоский 30 ₽/товар (уточнять, возможно акция) | расчёт по направлению/габаритам |
| Требование | кабинет продавца Ozon (FBO/FBS), РФ, ограничения самозанятого | договор + токен в ЛК |
| До двери | есть | есть, в т.ч. экспресс |
| Тестовое окружение | через private application | по странице — нет |
| Модель данных | `carrier='ozon'`, без новых колонок | `carrier='yandex'`, без новых колонок |

Решение — за владельцем после реальных отправок СДЭК. Технически добавить Ozon
дешевле, чем кажется, благодаря уже сделанной нейтральной модели ПВЗ.

## Открытые вопросы перед подключением Ozon

1. Подтвердить право торговать свечами как самозанятый/ИП в кабинете Ozon
   (категория, собственное производство, маркировка/сертификаты — см.
   [legal-business-guide.md](../legal-business-guide.md)).
2. Подтвердить **актуальный** тариф последней мили в ЛК (30 ₽ может вырасти).
3. Уточнить, обязателен ли реально активный FBO/FBS-кабинет (размещение товара на
   маркетплейсе) или достаточно зарегистрированного продавца ради логистики.
4. Возвраты невостребованных заказов: процесс и стоимость обратной логистики.
5. Договор/реквизиты и порядок расчётов магазин ↔ Ozon (постоплата/лицевой счёт).
