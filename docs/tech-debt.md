# Технический долг — МАВИТА-ШОП

Дата актуализации: 2026-06-30.

Этот файл — активный backlog технических и операционных долгов, которые должны
попадать в планирование roadmap. Уже исправленные дефекты удалены из активного
реестра; история остаётся в git, тестах и done-specs.

Источники статуса: [ROADMAP.md](../ROADMAP.md), [TESTING_PLAN.md](../TESTING_PLAN.md),
актуальные planning specs в `docs/specs/` и код `shop/`.

## Шкалы

**Приоритет**

- **P0** — release gate до приёма реальных денег или подтверждения production rollout.
- **P1** — усиление существующего production-контура после P0.
- **P2** — важная надёжность/безопасность без блокировки продаж.
- **P3** — backlog публичного checkout и антиабуза.
- **P4** — осознанный продуктовый/операционный долг, брать по сигналам роста.

**Сложность**

- **S** — точечная правка или ops-задача до 0.5 дня.
- **M** — 1-2 дня: код + тесты или несколько связанных ops-шагов.
- **L** — 3-5 дней: схема/миграции/UI/интеграционные тесты.
- **XL** — больше недели или требует отдельной спеки/бизнес-решения.
