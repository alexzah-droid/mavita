## Карточки товаров

### Артикул: 001

- **Название:** Каменная пирамида
- **Категория:** Аромасвеча
- **Серия:** Горы
- **Аромат:** «Ты — первооткрыватель!» — аромат путешествий, свежего лесного воздуха и духа приключений.
  - **Нотки:** свежая трава, бергамот, эвкалипт, пихта, можжевельник, тепло кожи, пачули
- **Цена:** 1600 ₽

**Описание.** Стильная ароматная пирамида из двух контейнерных свечей и универсальной крышки, которая подходит к обеим ёмкостям. «Ты — первооткрыватель!» — это аромат путешествий, свежего лесного воздуха, духа приключений. 100% натуральный соевый воск раскрывает аромат наилучшим образом: сначала вас захватывают ноты свежей травы и бергамота, затем свеча раскрывается эвкалиптом, пихтой и можжевельником, чтобы потом подарить невероятное тепло кожи и пачули. Целое путешествие в одной свече станет настоящим приключением и отличным подарком. Свеча бережно упаковывается в брендированную подарочную коробку с надёжной защитой.

*Ты — первооткрыватель.*

## Структура полей карточки товара

Источник маркетинговых данных для seed-каталога и карточек. Каноническая схема
БД — `shop/sql/schema.sql`; часть маркетинговых полей пока есть только в seed и
не редактируется через PostgreSQL.

| Поле | Источник / правило | Где в БД |
|---|---|---|
| Артикул | внутренний код (`001`…); используется как имя папки с фото | — |
| `slug` | URL-идентификатор латиницей; задаётся вручную при заведении товара | `products.slug` |
| Название | как в карточке; для серии «Симфония камней» форма указана в названии | `products.name` |
| Категория | `Аромасвеча` \| `Свеча`; сейчас только seed/контент, не колонка БД | — |
| Серия | коллекция (сейчас все — «Горы») | `products.series` |
| Аромат | название + короткое описание; в seed/контенте, отдельной колонки нет | `description` / seed `aroma` |
| Нотки | список нот аромата | `products.scent` |
| Цена | в карточке указана в ₽; **в БД хранится в копейках** (`INTEGER`): 1600 ₽ → `160000` | `products.price_kopecks` |
| Описание | маркетинговый текст карточки | `products.description` |
| Наличие | в продаже / нет | `products.in_stock` |
| Порядок | сортировка на витрине | `products.sort_order` |

### Фото

- Лежат в `docs/source/<артикул>/` — например `docs/source/001/`.
- Имена файлов: `01`, `02`, `03`… Обложка витрины — **всегда `01`** (`product_images.is_cover = true`).

### Атрибуты (добавляются позже)

Вес, размеры, время горения, состав воска, тип фитиля и т. п. выводятся на карточке и редактируются в админке. На этапе исходника не заполняются.
