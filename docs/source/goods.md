## Структура полей карточки товара

Источник маркетинговых данных для seed-каталога и карточек. Каноническая схема
БД — `shop/sql/schema.sql`.

| Поле | Источник / правило | Где в БД |
|---|---|---|
| Артикул | внутренний код (`001`…); используется как имя папки с фото | — |
| `slug` | URL-идентификатор латиницей; задаётся вручную при заведении товара | `products.slug` |
| Название | как в карточке; для серии «Симфония камней» форма указана в названии | `products.name` |
| Категория | `Аромасвеча` \| `Свеча`; сейчас только seed/контент, не колонка БД | — |
| Серия | коллекция (сейчас все — «Горы») | `products.series` |
| Подзаголовок | краткое позиционирование товара | `products.subtitle` |
| Аромат | название + короткое описание; в seed/контенте, отдельной колонки нет | `description` / seed `aroma` |
| Нотки | список нот аромата | `products.scent` |
| Цена | в карточке указана в ₽; **в БД хранится в копейках** (`INTEGER`): 1600 ₽ → `160000` | `products.price_kopecks` |
| Описание | маркетинговый текст карточки | `products.description` |
| Наличие | в продаже / нет | `products.in_stock` |
| Видимость | `public` (видно на витрине) \| `unlisted` (скрыто от каталога) \| `hidden` (неактивно) | `products.visibility` |
| Порядок | сортировка на витрине (возрастание) | `products.sort_order` |
| Скидка | опциональная промо-цена (в копейках) и период | `products.sale_price_kopecks`, `products.sale_starts_at`, `products.sale_ends_at` |

### Фото

- Лежат в `docs/source/<артикул>/` — например `docs/source/001/`.
- Имена исходников: `01`, `02`, `03`… При первоначальном импорте `01` разумно
  назначить обложкой; фактическая обложка хранится в `product_images.is_cover` и
  может быть изменена в админке.
