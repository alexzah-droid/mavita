# MAVITA — пакет стилей для редизайна

Два утверждённых направления для mavita.ru: **«Свет»** (светлое, природное, воздушное) и **«Камень»** (тактильное, фактурное). Этот пакет — для применения в реальном проекте.

## Файлы

| Файл | Что это |
|---|---|
| `mavita-tokens.css` | Дизайн-токены (цвет, шрифт, радиусы, отступы) для обоих направлений через `data-theme` |
| `mavita-components.css` | Готовые классы компонентов (`.mav-*`), работают на токенах |
| `reference-svet.html` | Эталонная вёрстка направления «Свет» — главная + товар |
| `reference-kamen.html` | Эталонная вёрстка направления «Камень» — главная + товар |

## Подключение

1. Шрифты в `<head>`:
   ```html
   <link href="https://fonts.googleapis.com/css2?family=Spectral:ital,wght@0,300;0,400;0,500;0,600;1,300;1,400;1,500&family=PT+Serif:ital,wght@0,400;0,700;1,400&family=Manrope:wght@300;400;500;600;700;800&display=swap" rel="stylesheet">
   ```
2. Стили:
   ```html
   <link rel="stylesheet" href="mavita-tokens.css">
   <link rel="stylesheet" href="mavita-components.css">
   ```
3. Выбрать направление атрибутом на `<body>` (или `<html>`):
   ```html
   <body data-theme="svet">   <!-- или data-theme="kamen" -->
   ```
   Для «Камень» добавьте класс `mav-noise` на корневой контейнер — даст каменную фактуру фона.

## Палитры

**Свет** — фон `#f3ede3`, подложка `#ebe3d6`, текст `#2c2620`, акцент шалфейный `#7d8a6a`, подписи глиняные `#9a8466`. Заголовки — Spectral Light/Italic.

**Камень** — фон `#cdc4b3` (+ noise), «плита» `#e8e1d3`, тёмная секция `#2a2520`, акцент мшистый `#5c6149`. Заголовки — PT Serif Bold. Карточки — горизонтальные «плиты» с тенью.

Общий бодитекст в обоих — **Manrope**.

## Ключевые компоненты

- `.mav-header` + `.mav-logo` — липкая шапка с блюром
- `.mav-h1` / `.mav-h2` / `.mav-eyebrow` / `.mav-lead` / `.mav-p` — типографика
- `.mav-btn` (`--primary` / `--solid` / `--outline` / `--block`) — кнопки
- `.mav-chips` + `.mav-chip` — ноты аромата
- `.mav-card` — карточка товара (Свет, вертикальная)
- `.mav-slab` — карточка-плита (Камень, горизонтальная)
- `.mav-grid-4` / `.mav-grid-2` — сетки каталога (адаптив встроен)
- `.mav-spec` — строки характеристик
- `.mav-dark` — тёмная brand-секция

Минимальные примеры разметки см. в `reference-*.html` — это эталон, по которому агент собирает страницы.

## Примечания

- Фото в эталонах — плейсхолдеры. Подставьте реальные снимки (главное фото товара 3:4 или 1:1, hero — широкий).
- Цены и тексты взяты с текущего сайта; проверьте перед публикацией.
- Адаптив (планшет/мобайл) уже заложен в `mavita-components.css`.
