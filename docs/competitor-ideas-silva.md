# Идеи с сайта Silva (silvacandle.ru) для МАВИТА

Дата: 2026-06-30
Сравнение: mavita.ru vs silvacandle.ru

## Структура mavita.ru (на момент анализа)

- Навигация: Каталог, Ритуал, О бренде, Доставка
- Каталог построен вокруг трёх стихий: Лес, Море, Горы
- Фишка — QR-ритуал (4 шага: зажечь свечу → сканировать QR на открытке → включить аудиодорожку с природными звуками → погружение)
- История основателя Виктории, расшифровка названия "МА — Земля, ВИТА — жизнь"
- Соцсети: только ВКонтакте
- Темы оформления: тёмная, светлая, каменная

## Структура silvacandle.ru (для сравнения)

- Навигация: Главная, Коллекция, Концепция, Отзывы, FAQ
- УТП: ручная работа, вариации размера (±0,5–1 см) поданы как авторский почерк, а не брак
- Коллаборация SILVA x FABERZHENYA — лимитированные карточки-трансформеры с иллюстрациями
- Опция заказа без магнита — специально для подарков
- Соцсети: Instagram, Telegram, VK, Pinterest

## Идеи к переносу в МАВИТА

1. **Раздел «Отзывы» в навигации** — у МАВИТА нет видимого социального доказательства. Для бренда с акцентом на эмоциональный опыт (QR-ритуал) отзывы — сильный конвертер.

2. **FAQ-раздел** — снимает типовые вопросы до контакта с поддержкой: как горит, сколько хватает, как ухаживать, что делать с QR-кодом, если потерялась открытка.

3. **Больше соцсетей, особенно Telegram** — сейчас только VK. Telegram — основной канал для бренд-комьюнити в РФ.

4. **Переосмысление "несовершенств" как авторской подписи** — по аналогии с текстом Silva про вариации размера. Для каменных свечей МАВИТА (форма камня естественно уникальна) — готовый текстовый ход: "каждая свеча немного отличается" превращается из недостатка в УТП.

5. **Лимитированные коллаборации** — сезонные/лимитированные выпуски с приглашёнными иллюстраторами или подарочная упаковка под конкретный повод для линеек "Лес"/"Море"/"Горы".

6. **Версия без QR-открытки для подарков** — упрощённая подача для тех, кто хочет просто красивую свечу без "ритуала" (по аналогии с опцией "без магнита" у Silva).

## Приоритет

Самое дешёвое и быстрое в реализации: пункты 1, 2, 3 (отзывы, FAQ, Telegram) — закрывают явные пробелы в доверии и охвате без изменения продукта.
