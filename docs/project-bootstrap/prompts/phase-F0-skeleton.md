# Промпт Ф0: каркас МАВИТА-ШОП

> Использовать, когда владелец даёт старт реализации Фазы 0.

Начинаем Фазу 0 «Проектный фундамент» МАВИТА-ШОП.

Перед работой прочитай:

1. `PROJECT_CORE.md`;
2. `DOCS.md`;
3. `architecture.md`;
4. `TESTING_PLAN.md`.

Работай автономно по контракту из `PROJECT_CORE.md`.

Останавливайся только если:

- затрагиваешь Робокассу в prod-режиме, реальные деньги или production-сервер — **Пауза 1**;
- нужен выбор с долгосрочными последствиями (смена схемы БД, стека, деплоя) — **Пауза 2**: варианты + рекомендация.

---

## Задача Ф0

1. Инициализировать Next.js 15 App Router проект в корне репозитория рядом с КП-материалами.
2. Завести `sql/schema.sql` — полная DDL схема из `architecture.md` §База данных.
3. Завести `lib/db.ts` — Postgres-клиент (postgres.js).
4. Завести `lib/robokassa.ts` — функции `buildSignature` и `verifySignature` с тестами.
5. Завести `lib/auth.ts` — iron-session для защиты админки.
6. Завести скелет API-роутов: `/api/robokassa/result`, `/api/robokassa/init`, `/api/robokassa/success`, `/api/robokassa/fail`.
7. Завести скелет страниц: витрина `/`, карточка `/product/[slug]`, корзина `/cart`, оформление `/checkout`, `/admin`.
8. Завести `.env.example` с переменными из `architecture.md` §Переменные окружения.
9. Завести `sql/seed.sql` — 2-3 тестовых товара для локального запуска.
10. Убедиться, что `npm run dev` стартует без ошибок.
11. Обновить `PROJECT_CORE.md` с фактической readiness-командой.
12. Обновить `TESTING_PLAN.md` с первыми зелёными строками.
13. Обновить `DOCS.md`, если появились новые документы.

## Критерий выхода Ф0

- свежий клон: `npm install` + `psql -f sql/schema.sql` + `psql -f sql/seed.sql` + `npm run dev` — работает без ручных шагов;
- витрина `/` возвращает 200, отображает тестовые товары;
- `POST /api/robokassa/result` с неверной подписью возвращает 400 (тест в `TESTING_PLAN.md`);
- `lib/robokassa.ts` покрыт unit-тестами на подпись;
- `.env.example` содержит все переменные из `architecture.md`.

## Не делать в Ф0

- реальный деплой на сервер;
- подключение к prod Робокассе;
- загрузку реальных фото;
- `docs/environments.md` и `docs/operations.md` — только если появился внешний стенд.
