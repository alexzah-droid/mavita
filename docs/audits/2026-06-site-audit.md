## ⚠️ ЧТО ТРЕБУЕТ ВНИМАНИЯ

### 1. SEO — Нужно развивать (Приоритет: СРЕДНИЙ)

❌ **Что не хватает:**

**На главной странице:**
- Нет H1 заголовка (хотя есть большой текст "МАВИТА")
- Структурированные данные (schema.org) для товаров не видны

**Для товаров:**
- Если нет отдельных страниц товаров с уникальным контентом — это проблема для SEO
- Каждый товар должен быть в индексе поисковиков

**Google индексация:**
- Добавить robots.txt (если его нет)
- Добавить sitemap.xml (список всех страниц)
- Подключить Google Search Console

**Meta-теги товаров:**
- Каждый товар должен иметь уникальные title и description

📝 **Рекомендация:**
```
Добавить в <head>:
1. Structured data (JSON-LD) для каждого товара
2. Open Graph теги для соцсетей (og:title, og:description, og:image)
3. sitemap.xml
4. robots.txt
```

### 2. Безопасность — На хорошем уровне, но есть нюансы (Приоритет: СРЕДНИЙ)

✅ **Что хорошо:**
- HTTPS включен
- Данные карт не обрабатываются на вашем сервере (Robokassa)

⚠️ **Что нужно проверить:**

**1. Rate limiting на формах**
- Есть ли защита от перебора пароля (если есть регистрация)?
- Есть ли защита от spam-заказов?

**2. CORS (Cross-Origin Resource Sharing)**
- Если API открыт — убедитесь, что он не доступен со всех доменов
- Ограничьте доступ только к вашему фронтенду

**3. CSP (Content Security Policy)**
- Добавить заголовок `Content-Security-Policy` для защиты от XSS
- Ограничить inline скрипты

**4. Капча на форме заказа**
- Рекомендуется добавить reCAPTCHA v3 (Google) для защиты от ботов
- Это защитит от автоматических заказов с фиктивными данными

📝 **Рекомендация:**
```
Добавить в Response Headers:
1. Content-Security-Policy: default-src 'self'; script-src 'self' https://www.google.com/recaptcha/; ...
2. X-Frame-Options: DENY (если не нужны iframe)
3. X-Content-Type-Options: nosniff
4. Strict-Transport-Security: max-age=31536000; (HSTS)
```

### 4. Описание товаров — Минимально (Приоритет: СРЕДНИЙ)

⚠️ **Текущее состояние:**

Товары описаны очень кратко:
- "Симфония камней №2 (куб) - Горы - Тайна застывшей лавы - 6 700 ₽"

❌ **Что не хватает на странице товара:**

1. **Полное описание**
   - Размер (см или мм)
   - Вес товара
   - Вид воска (парафин, соевый, пчелиный)
   - Время горения (часов)
   - Ингредиенты (какие масла используются)

2. **Информация о качестве**
   - Сертификаты соответствия (если есть)
   - Декларация соответствия товара (ВАЖНО для свечей!)
   - "Ручная работа" подробнее

3. **Рекомендации по использованию**
   - Как правильно зажечь
   - Советы по длительности горения
   - Где лучше использовать

4. **Отзывы**
   - Нет системы отзывов на сайте
   - Рекомендуется добавить (повышает доверие, SEO)

📝 **Рекомендация:**

На каждой странице товара (если они есть) добавить:
```
- Характеристики:
  * Размер: 7x7x7 см
  * Вес: 180 г
  * Материал: Соевый воск
  * Время горения: ~15 часов
  * Ароматический состав: Пихта, кипарис, можжевельник

- Описание (2-3 абзаца):
  * Что это за аромат
  * Какие чувства он вызывает
  * Когда его лучше использовать

- В конце: "Декларация соответствия № ..."
```
