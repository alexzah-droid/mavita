# PROJECT_CORE — МАВИТА-ШОП

Дата актуализации: 2026-07-09

Этот документ — единый источник фактов о проекте. Читается первым в любой рабочей сессии.

---

## 1. Суть проекта

Интернет-магазин свечей МАВИТА: витрина, корзина, оплата через Робокассу, админ-панель для управления товарами, фотографиями, заказами и доставкой СДЭК.

Стек: Next.js 15 (App Router) + PostgreSQL 16 + Nginx + PM2 на Ubuntu 22.04 VPS (`mavita.ru`, `45.130.147.108`).

## 5. Инварианты

Нарушение любого — стоп, Пауза 2.

| ID | Инвариант |
| --- | --- |
| I1 | Подпись Робокассы считается **только** на сервере в `lib/robokassa.ts`. Password1/Password2 — только в `.env`. |
| I2 | Цены хранятся в копейках как `INTEGER`. FLOAT для цен запрещён. |
| I3 | `POST /api/robokassa/result` меняет статус заказа **только** после успешной проверки подписи (алгоритм — `ROBOKASSA_HASH_ALGO`; на проде SHA-256 с 2026-06-23, синхронно с ЛК). |
| I4 | Статус заказа меняется только через API, не прямым `UPDATE` в БД. |
| I5 | Фото загружается только через admin-only `POST /api/upload`; файл и запись в `product_images` создаются компенсируемо-атомарно, без анонимных или непривязанных файлов. |
| I6 | `index.html` не редактируется вручную — это сгенерированный бандл КП. |
| I7 | `.env` с реальными секретами никогда не коммитится. |
| I8 | Каждый `/api/admin/**`, `/api/upload` и каждая защищённая `/admin/**`-страница выполняет работу только после `requireAdminApi()` / `requireAdminPage()`; исключения — login/logout. Изменяющие запросы проверяют same-origin. Пароль/секрет — только в `.env`, сравнение — `timingSafeEqual` SHA-256 digest одинаковой длины. |
| I9 | Цена позиции заказа — это `effectivePrice()` по заблокированному в транзакции срезу БД в момент создания заказа. Видимость/цена с клиента игнорируются; `hidden`-товар купить нельзя. |
| I10 | Итог заказа равен серверному snapshot `товары + доставка`; клиент не задаёт цену доставки. Платёжный и исполнительский статусы разделены: ни один ручной шаг отгрузки не может установить `paid`. |

## 6. Текущий статус

Источник статуса фаз и чек-листов — **`ROADMAP.md`** (здесь не дублируется, чтобы не расходиться).

Магазин работает на production в боевом режиме:

- **Робокасса** — боевой режим (`ROBOKASSA_TEST_MODE=false`) с 2026-06-21 (Пауза 1
  пройдена), подпись SHA-256 с 2026-06-23; реальные оплаты проходят.
- **СДЭК-ПВЗ** — включён на checkout с 2026-06-24 (`DELIVERY_ENABLED=true`), выбор
  города/ПВЗ через виджет; автосоздание накладных задеплоено (dark launch,
  `cdek_auto_shipment_enabled` управляется из админки).
- **Telegram-уведомления владельцу** — работают с 2026-06-23 (outbox + systemd-таймер).
- **Аналитика** — Метрика с событиями воронки `add_to_cart`/`begin_checkout`/`purchase`
  (2026-07-02).
- Миграции `001`–`022` применены на проде (миграция `022` и значения веса
  чистого воска подтверждены 2026-07-09).

Ф0–Ф4 готовы; из Ф5 остаётся автоматизация деплоя (GitHub Actions). Текущее
направление: рост конверсии витрины, усиление админ-доступа (P1 в
[ROADMAP.md](ROADMAP.md)) и расширение доставки по актуальным specs. Любое действие
на production по-прежнему требует Паузы 1.
