# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project overview

Static HTML commercial proposal (КП — коммерческое предложение) for the МАВИТА brand. No build system, package manager, or test suite — everything is plain HTML/CSS/JS.

## Viewing the files

Open any `.html` file directly in a browser, or serve locally:

```bash
python3 -m http.server 8080
# then open http://localhost:8080
```

## Key files

- **`index.html`** — The primary deliverable. A self-contained "bundled" HTML (~6 MB) generated by a custom bundler that embeds all assets (images, fonts, JS, CSS) as base64 in two embedded `<script>` tags:
  - `<script type="__bundler/manifest">` — JSON map of asset UUIDs → base64 data + MIME type + compression flag
  - `<script type="__bundler/template">` — the full HTML template with UUID placeholders

  At runtime, the inline JS loader decodes and inflates assets (using `DecompressionStream` for compressed ones), creates blob URLs, substitutes UUIDs in the template, then replaces the document root with the rendered page. **Do not edit `index.html` manually** — it is a generated output file.

- **`Мавита - четыре направления (один файл).html`** — A hand-authored standalone multi-page HTML presentation covering МАВИТА's four business directions. Uses Google Fonts (Cormorant Garamond + Manrope) loaded from CDN. This file *can* be edited directly.

- **`mavita_kp.pdf`** — The same commercial proposal in PDF form (identical content to `МАВИТА · Коммерческое предложение для партнёров.pdf`).

- **`Мавита_КП_02.zip`** — Latest packaged release of the proposal assets; `archive/` holds a copy.

## Design system

Both HTML files share a consistent visual language:

| Token | Value |
|-------|-------|
| Background | `#1c1812` / `#221c14` |
| Paper / text | `#efe5cf` |
| Accent (ember) | `#d28a55` / `#b7704a` |
| Accent (moss) | `#a8c478` |
| Body font | Manrope 300/400/500 |
| Display font | Cormorant Garamond 400/500 |
